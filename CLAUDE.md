# xerocode

Клиентский Fabric-мод для Minecraft 1.21.11 — визуальный редактор кода JustMC Creative+.
Блоки кода рисуются на 2D-полотне, читаются из мира (`/dev`) и отправляются обратно на сервер.

## Сборка

```
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew build
```

Java не в PATH — `JAVA_HOME` задавать обязательно. Jar появляется в `build/libs/`.
Версия мода — `mod_version` в `gradle.properties`.

## Стиль кода

- **Комментариев в коде нет.** Ни `//`, ни javadoc — код объясняет себя именами и структурой.
  Если фрагмент требует комментария, его надо переписать.
- Классы `final`, утилитные — с приватным конструктором и статикой.
- Всё, что не нужно снаружи, — `private`. Публичный API держится узким.
- Тексты интерфейса и логи — на русском, короткие; строки-константы наверху класса.
- Отступ 4 пробела, ширина строки ~100.

## Что где

- `com.xerocode` — модель и обмен с сервером: `Script` (полотно), `Catalog` (каталог блоков),
  `Importer`/`Exporter` (json сервера), `Codespace` (чтение кода из мира), `Sync` (слепок мира
  против полотна), `Publish`, `Collab`, `Market`.
- `com.xerocode.ui` — экраны и отрисовка: `EditorScreen` (полотно), `Layout` (раскладка блоков),
  `Draw`/`Ui`/`Theme` (примитивы и цвета), `DialogScreen` (общая база диалогов).
- Данные каталога — `src/main/resources/assets/xerocode/`.
